# MechanicsFit Automate — Abaqus V0.1.1 Private Beta

This beta is for Abaqus users who regularly process multiple ODB files and want to reduce repetitive post-processing.

It provides ODB inspection, batch S/Mises, displacement, reaction-force and PEEQ extraction, user-defined engineering checks, case comparison, reusable workflows, Excel export, and HTML reports. ODB processing is local; files are not uploaded.

To try it: download and extract `MechanicsFit-Automate-Abaqus-V0.1.1-Private-Beta.zip`; double-click **Start MechanicsFit.bat**; try the synthetic Demo; configure your local Abaqus installation; process real ODB files; compare at least one result manually with Abaqus/CAE; then submit feedback from inside MechanicsFit. Stop the local server with **Stop MechanicsFit.bat**.

Windows and Python 3.11 are required. Abaqus 2025 is the primary validated integration environment. Other Abaqus versions need broader validation. Demo Mode works without Abaqus. This beta does not certify model or result correctness.
