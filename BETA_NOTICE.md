# Private Beta notice

MechanicsFit Automate — Abaqus V0.1.1 is a Windows-focused private beta for local batch ODB post-processing. Abaqus 2025 is the primary validated integration environment. Demo Mode uses synthetic, precomputed data and does not require Abaqus.

Please independently verify critical engineering results against Abaqus/CAE before using them in engineering decisions. The tool does not validate or certify an FEA model. Real ODB processing requires a local Abaqus installation and ODB API.

ODB files, extracted results, and diagnostic bundles remain local unless you choose to share them. The app has no automatic upload or telemetry. Its beta feedback link opens an external Google Form only when selected.
